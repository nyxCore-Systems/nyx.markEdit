## 3. The "Pain" Log (CRITICAL)
* **Tried:** `WKPDFConfiguration().createPDF()` for A4 export.
  * **Failed:** PDF used webView frame as page size → oversized text, no A4 pagination. Even resizing webView to 595×842 pt before calling createPDF was unreliable.
  * **Workaround:** Switched to `webView.printOperation(with: NSPrintInfo)` with `paperSize`, `topMargin`, etc., set explicitly. `op.showsPrintPanel = false`, `op.runModal(for: window, ...)` for unattended save via `attrs[.jobSavingURL]`.
  * *Note:* Don't go back to createPDF for paged output. WKPDFConfiguration is good only for single-page snapshots.
* **Tried:** Hand-writing `NativeModuleAI.swift` in `MarkEditKit/Sources/Bridge/Native/Generated/` to skip `yarn codegen`.
  * **Failed:** When user later ran `yarn codegen` the generator overwrote my file. Types I had defined there (`AIRefactorResponse`) disappeared because they're not used in the TS bridge interface (returns `string`).
  * **Workaround:** Helper types must live OUTSIDE `Generated/`. Moved `AIRefactorResponse` to `Modules/EditorModuleAI.swift`.
  * *Note:* Treat `Generated/` as truly read-only/regeneratable.
* **Tried:** Returning `AIRefactorResponse` Codable struct from bridge method.
  * **Failed:** `WKScriptMessageHandlerWithReply` only auto-marshals NSDictionary/NSArray/NSString/NSNumber/NSDate/NSNull — not Swift Codable structs. JS got `undefined`.
  * **Workaround:** Bridge methods returning complex objects must JSON-encode to `String` (matches existing `LanguageModelResponse.jsonEncoded` pattern in `EditorModuleFoundationModels`). TS side `JSON.parse`s.
* **Tried:** Calling `view.coordsAtPos()` and `getBoundingClientRect()` directly inside CodeMirror `ViewPlugin.update()`.
  * **Failed:** `CodeMirror plugin crashed: Reading the editor layout isn't allowed during an update`.
  * **Workaround:** `this.view.requestMeasure({ read: () => this.reposition() })` to defer the layout read into the measure phase.
* **Tried:** Custom `presentError(_:)` method on `RendererWindowController`.
  * **Failed:** Ambiguous with inherited `NSResponder.presentError(_:)`.
  * **Workaround:** Renamed to `showErrorAlert(_:)`.
* **Tried:** Building Release with `-derivedDataPath ./build`.
  * **Failed:** SwiftLint flagged auto-generated `resource_bundle_accessor.swift` files in DerivedSources (`trailing_newline`).
  * **Workaround:** Added `**/DerivedSources/**` and `build` to `.swiftlint.yml` `excluded:` list.
* **Tried:** Pasting multi-line `osascript -e 'do shell script "..."'` install commands into the chat-shell.
  * **Failed:** (a) Some chat clients turned `"` into `”` (smart-quote substitution) → `syntax error: Expected string but found end of script`; (b) embedded newlines made `do shell script` interpret each line as a separate command, causing `cp ... is a directory` and `--sign: command not found`.
  * **Workaround:** Wrote install steps to `/tmp/install_markedit.sh`, then `osascript -e 'do shell script "/tmp/install_markedit.sh" with administrator privileges'`. Single ASCII string, no quote-or-newline traps.
  * *Note:* For any future install or admin-priv shell sequences, use a temp script file. Don't inline.
* **Tried:** `sudo bash -c '...'` via the headless Bash tool.
  * **Failed:** `sudo: a terminal is required to read the password`. Same problem with `sudo -S` since no stdin password.
  * **Workaround:** `osascript ... with administrator privileges` triggers macOS GUI auth (Touch ID), which works without TTY.
* **Tried:** ESLint strict-boolean-expressions on `response.error || !response.result`.
  * **Failed:** Nullable string in a boolean context is forbidden under the project's eslint config.
  * **Workaround:** Helper `isNonEmpty(value): value is string` and explicit `if/else` branches.
