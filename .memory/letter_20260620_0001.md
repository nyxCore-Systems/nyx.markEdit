## 3. The "Pain" Log (CRITICAL)
* **MarkEditMac Xcode target uses an EXPLICIT `project.pbxproj` file list** (no `PBXFileSystemSynchronizedRootGroup`). New `.swift` files must be added in 4 places (PBXBuildFile, PBXFileReference, group children, Sources phase) or you get `cannot find X in scope`. The prior AI feature used hand-assigned IDs `9AB1000000000000000B000X`; I continued with B0007–B000A.
* **SwiftLint runs as a build plugin and FAILS the build.** Hit: `pattern_matching_keywords` (use `case let .x(a, b)`), `prefer_self_in_static_references` (use `Self(...)`), `superfluous_disable_command` (don't add `// swiftlint:disable type_name` on a long-enough type name). `enum NyxCore` did NOT need the disable that `enum AI` has.
* **nyxCore MCP transport:** stateless JSON-RPC works — NO `initialize` handshake / session needed. Verified via curl. Send `Accept: application/json, text/event-stream`.
* **`corepack enable` fails with EACCES** (symlink to /usr/local/bin) but `yarn install`/`yarn build` work anyway (Yarn 4.9.2 present). Node is 26.x though project wants 22.x — builds fine regardless.
* The editor web bundle (`CoreEditor/dist`) is embedded at Xcode build time, so any TS/CSS change requires `yarn build` AND a fresh Xcode (re)build/reinstall.
