## 3. The "Pain" Log (CRITICAL)
* **Tried:** marked v14 with old `renderer.code = function(code, infostring)` signature.
  * **Failed:** `infostring` is undefined in v14 — the renderer receives a token object as a single arg. `lang` resolved to `""`, so my mermaid + highlight.js detection never fired and code blocks rendered as plain `<pre><code>` with no special handling.
  * **Workaround:** Branch on `typeof codeOrToken === "object"` and read `token.text` / `token.lang`; keep the legacy two-arg path for older marked versions.
  * *Note:* Whenever overriding marked renderers, target v14's token-based API; keep a legacy fallback only if the dependency is truly unpinned.
* **Tried:** Adding `.insertPageBreak` to `defaultItems` and expecting it to show up automatically.
  * **Failed:** NSToolbar persists user customization across launches; pre-existing `MarkEditMac` users see their saved toolbar config and never see the new default item.
  * **Workaround:** Tell user to right-click the toolbar → **Customize Toolbar…** and drag the new item in. (No code change.)
* **Tried:** `width: 210mm` paper layout in a default 540pt-wide preview window.
  * **Failed:** A4 (≈793px at 96 dpi) was wider than the preview window → no visible canvas margin, looked like before.
  * **Workaround:** Bumped `Renderer.swift` `Constants.defaultWidth = 880`, `minimumWidth = 820`, `defaultHeight = 1000`. Strengthened paper shadow + canvas contrast for readability.
